## How To Host

**Cloudflare Pages:**
1. Create account on Cloudflare.com
2. Go to Pages > Create Application > Upload
3. Upload the full folder
4. Add Custom Domain theredeye.co.in

**Netlify:**
1. Create account on Netlify.com
2. Drag and Drop the full folder
3. Add Domain theredeye.co.in in Domain Settings

## How To Convert To APK
